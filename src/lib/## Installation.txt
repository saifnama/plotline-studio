## Usage
Create an SVG element with explicit width and height:

```
<svg id="markmap" style="width: 800px; height: 800px"></svg>
```


```
<svg id="markmap" style="width: 800px; height: 800px"></svg>
```

Assuming we have already got { root } node and assets { styles, scripts } from [markmap-lib](https://markmap.js.org/docs/packages--markmap-lib).

```
{ root }
```


```
{ styles, scripts }
```

There are two ways to import markmap-view:

```
markmap-view
```


```
// load with <script> const { markmap } = window; const { Markmap, loadCSS, loadJS } = markmap; // or as ESM import * as markmap from 'markmap-view'; import { Markmap, loadCSS, loadJS } from 'markmap-view';
```


```
// load with <script> const { markmap } = window; const { Markmap, loadCSS, loadJS } = markmap; // or as ESM import * as markmap from 'markmap-view'; import { Markmap, loadCSS, loadJS } from 'markmap-view';
```

Now we can render a markmap to the SVG element:

```
// 1. load assets if (styles) loadCSS(styles); if (scripts) { loadJS(scripts, { // For plugins to access the `markmap` module getMarkmap: () => markmap, }); } // 2. create markmap // `options` is optional, i.e. `undefined` can be passed here Markmap.create('#markmap', options, root); // -> returns a Markmap instance
```


```
// 1. load assets if (styles) loadCSS(styles); if (scripts) { loadJS(scripts, { // For plugins to access the `markmap` module getMarkmap: () => markmap, }); } // 2. create markmap // `options` is optional, i.e. `undefined` can be passed here Markmap.create('#markmap', options, root); // -> returns a Markmap instance
```

The first argument of Markmap.create can also be an actual SVG element, for example:

```
Markmap.create
```


```
const svgEl = document.querySelector('#markmap'); Markmap.create(svgEl, options, data); // -> returns a Markmap instance
```


```
const svgEl = document.querySelector('#markmap'); Markmap.create(svgEl, options, data); // -> returns a Markmap instance
```
