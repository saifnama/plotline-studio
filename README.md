# Plotline Studio

Plotline Studio is an interactive, browser-based diagramming tool that supports Flowcharts, Database Diagrams (DBML), and native Markdown Mindmaps (Markmap).

## Features
- **Flowchart Editor**: Write Mermaid syntax, visualize instantly.
- **Database Diagram**: Write DBML and preview ER diagrams. Export to SQL.
- **Mindmap Editor**: Write standard Markdown and preview vibrant Markmap trees.
- **Exporting**: Export to PNG, JPG, or SVG with transparent, light, or dark themes.

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   `npm install`
2. Run the app:
   `npm run dev`
